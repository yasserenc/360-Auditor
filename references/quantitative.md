# Quantitative and Calculation Audit

Use this reference for arithmetic, financial/non-financial calculations, conversions, estimates, statistics, sizing, percentages, rates, and quantitative comparisons.

## Recompute independently

1. Restate the material input values and their units/source.
2. Write the governing formula or transformation in concise form.
3. Recalculate intermediate values independently rather than copying the prior result.
4. Check unit consistency, conversion factors, signs, denominators, percentages versus percentage points, and order of operations.
5. Check boundaries, rounding policy, significant digits, and whether the output precision is justified by the inputs.
6. For estimates, separate measured inputs from assumptions and show how sensitive the result is to assumptions when that could change the conclusion.
7. Cross-check with a second method or inverse calculation when cheap and useful.

## Statistical claims

When applicable, verify the population/sample, denominator, weighting, confidence/uncertainty, aggregation method, base rates, and whether averages hide relevant distribution effects.

Do not imply accuracy beyond the source data. If an exact figure cannot be supported, use an appropriately bounded estimate and label it as such.
